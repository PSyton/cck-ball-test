# zmk-config for CCK_BALL (4x6)
![](https://github.com/user-attachments/assets/34d4351d-cbd9-4c82-a2e0-c7c9d28c5942)

From the default documentation as sent by the seller/manufacturer:

```
1. MO(1)+keys in the first row = F1~F12
2. MO(1)+MO(2) (or MO(1)+H) = left mouse button
3. MO(1)+Right Space (or MO(1)+J) = Right Mouse Button
4. Press and hold the F button to enter scroll mode: Roll the trackball to achieve interface scroll mode, and release it to restore the default pointer mode.
5. Press and hold the S button to enter sniper mode: the trackball DPI will be reduced to a very low level (400dpi), allowing for finer mouse pointer movement. Release the button to restore to the default setting (1200dpi).
6. MO(2)+A=clear all devices bound to Bluetooth channels
7. MO(2)+C=Clear the device bound to the current Bluetooth channel
8. MO(2)+N=Switch to the next Bluetooth channel
9. MO(2)+1~5=Switch to the 1st to 5th Bluetooth channels
```

Where:
- MO1 is the rightmost thumb key the left keyboard
- MO2 is the leftmost thumb key the right keyboard

## Notes on flashing:
Always flash left first and then right. For a full reset, flash the reset firmware on each keyboard first 
and then flash the left and right firmwares separately
