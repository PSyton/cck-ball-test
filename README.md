# CCK BALL — ZMK конфигурация

![](https://github.com/user-attachments/assets/34d4351d-cbd9-4c82-a2e0-c7c9d28c5942)

Кастомная 4×6 сплит-клавиатура на nice!nano v2 с трекболом PMW3610, роторными энкодерами и RGB-подсветкой.

---

## Раскладка

### Обозначения

| Символ | Значение |
|--------|----------|
| `===`  | Прозрачная клавиша (передаётся на нижний слой) |
| `___`  | Отключённая клавиша |
| `HRM`  | Home-row mod: удержание = модификатор, тап = символ |
| `LT`   | Layer-tap: удержание = слой, тап = символ |
| `▸En / ▸Ru` | Макрос переключения базового слоя |

Домашний ряд использует **home-row mods** (HRM) с параметрами `balanced`, tapping-term 250 мс:

```
Левая рука:  A/Ф=LT(Sym)  R/Ы=Alt  S/В=Ctrl  T/А=Shift
Правая рука: O/Щ=LT(Sym)  I/Ш=Alt  E/Л=Ctrl  N/О=Shift
```

### Слой 0 — En (Colemak-DH)

Базовый английский слой на основе Colemak-DH.

```
┌─────┬─────┬─────┬─────┬─────┬─────╥─────┬─────┬─────┬─────┬─────┬──────┐
│ ESC │ ___ │ ___ │ ___ │ ___ │ ___ ║ ___ │ ___ │ ___ │ ___ │ ___ │ BSPC │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼──────┤
│ TAB │  Q  │  W  │  F  │  P  │  B  ║  J  │  L  │  U  │  Y  │ ___ │ ___  │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼──────┤
│ ___ │LT·A │Alt·R│Ctl·S│Sft·T│  G  ║  M  │Sft·N│Ctl·E│Alt·I│LT·O │ ___  │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼──────┤
│ ▸En │  X  │  C  │  D  │  V  │  Z  ║  K  │  H  │ ___ │ ___ │ ___ │ ▸Ru  │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼──────┤
│ ___ │ ___ │ ___ │SPC⁴ │BSPC │ DEL ║LCLK │RCLK │ENT⁴ │ ___ │ ___ │ ___  │
└─────┴─────┴─────┴─────┴─────┴─────╨─────┴─────┴─────┴─────┴─────┴──────┘
                       ╰──────────────────╯ ╰──────────────────╯
                         тамбкластер (L)       тамбкластер (R)
```

> `LT·X` — удержание активирует **Sym-en** (слой 1), тап — символ  
> `SPC⁴` / `ENT⁴` — удержание активирует **F_layers** (слой 4)  
> Левый энкодер: прокрутка вверх/вниз · Правый энкодер: прокрутка влево/вправо

### Слой 1 — Sym-en (символы для английского)

Активируется удержанием `A` или `O` в слое En.

```
┌─────┬─────┬─────┬─────┬─────┬─────╥─────┬─────┬─────┬─────┬─────┬─────┐
│ === │ === │ === │ === │ === │ === ║ === │ === │ === │ === │ === │ === │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│  `  │  ~  │  <  │  >  │  -  │  |  ║  ^  │  {  │  }  │  $  │  '  │ ___ │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│ === │  !  │  *  │  /  │  =  │  &  ║  #  │  (  │  )  │  ;  │  "  │ ___ │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│ ▸En │  ?  │  +  │  [  │  ]  │  %  ║  @  │  :  │  ,  │  .  │  /  │ ▸Ru │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
```

> `—` — длинное тире (em dash) · `–` — короткое тире (en dash)  
> `«` `»` — русские типографские кавычки при работе в английской раскладке ОС

### Слой 2 — Ru (русский QWERTY)

Базовый русский слой. ОС должна быть переключена в русский язык ввода.  
Переключение языка ОС происходит автоматически через макрос `▸Ru` / `▸En`.

```
┌─────┬─────┬─────┬─────┬─────┬─────╥─────┬─────┬─────┬─────┬─────┬─────┐
│ ESC │ ___ │ ___ │ ___ │ ___ │ ___ ║ ___ │ ___ │ ___ │ ___ │ ___ │BSPC │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│ TAB │  Й  │  Ц  │  У  │  К  │  Е  ║  Н  │  Г  │  Ш  │  Щ  │  З  │  Х  │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│  Ё  │LT·Ф │Alt·Ы│C*·В │Sft·А│  П  ║  Р  │Sft·О│C*·Л │Alt·Д│LT·Ж │  Э  │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│ ▸En │  Я  │  Ч  │  С  │  М  │  И  ║  Т  │  Ь  │  Б  │  Ю  │  Ъ  │ ▸Ru │
├─────┼─────┼─────┼─────┼─────┼─────╫─────┼─────┼─────┼─────┼─────┼─────┤
│ ___ │ ___ │ ___ │SPC⁴ │BSPC │ DEL ║LCLK │RCLK │ENT⁴ │ ___ │ ___ │ ___ │
└─────┴─────┴─────┴─────┴─────┴─────╨─────┴─────┴─────┴─────┴─────┴─────┘
```

> `LT·X` — удержание активирует **Sym-ru** (слой 3)  
> `C*` — удержание активирует Ctrl + временно переключает ОС на английский язык (для горячих клавиш приложений)

### Слой 3 — Sym-ru (символы для русского)

Активируется удержанием `Ф` или `Ж` в слое Ru.  
Символы, недоступные в русской раскладке ОС, вводятся через макрос `in_en` — временное переключение ОС на английский, нажатие символа, возврат в русский.

```
┌──────┬──────┬──────┬──────┬──────┬──────╥──────┬──────┬──────┬──────┬──────┬──────┐
│ ===  │ ===  │ ===  │ ===  │ ===  │ ===  ║ ===  │ ===  │ ===  │ ===  │ ===  │ ===  │
├──────┼──────┼──────┼──────┼──────┼──────╫──────┼──────┼──────┼──────┼──────┼──────┤
│ `ᵉⁿ  │  ~ᵉⁿ │  <ᵉⁿ │  >ᵉⁿ │  -   │  |ᵉⁿ ║  ^ᵉⁿ │  {ᵉⁿ │  }ᵉⁿ │  $ᵉⁿ │  'ᵉⁿ │ ___  │
├──────┼──────┼──────┼──────┼──────┼──────╫──────┼──────┼──────┼──────┼──────┼──────┤
│ ===  │  !   │  *   │  /ᵉⁿ │  =   │  &ᵉⁿ ║  #ᵉⁿ │  (   │  )   │  ;ᵉⁿ │  "   │ ___  │
├──────┼──────┼──────┼──────┼──────┼──────╫──────┼──────┼──────┼──────┼──────┼──────┤
│ ▸En  │  ?   │  +   │  [ᵉⁿ │  ]ᵉⁿ │  %   ║  @ᵉⁿ │  :   │  ,   │  .   │  /ᵉⁿ │ ▸Ru  │
├──────┼──────┼──────┼──────┼──────┼──────╫──────┼──────┼──────┼──────┼──────┼──────┤
│ ===  │ ===  │ ===  │  —   │  –   │  _   ║ ===  │ ===  │ ===  │ ===  │ ===  │ ===  │
└──────┴──────┴──────┴──────┴──────┴──────╨──────┴──────┴──────┴──────┴──────┴──────┘
```

> `ᵉⁿ` — символ вводится через временное переключение ОС в английский режим  
> Этот слой также активирует **режим прокрутки** трекбола (XY → скролл, делитель ×8)

### Слой 4 — F_layers (F-клавиши, навигация, Bluetooth)

Активируется удержанием `SPC` или `ENT` в базовых слоях.

```
┌─────┬─────┬─────┬─────┬─────┬─────╥──────┬──────┬──────┬──────┬──────┬────────┐
│ === │ === │ === │ === │ === │ === ║ BT0  │ BT1  │ BT2  │ BT3  │ BT4  │BT_CLR  │
├─────┼─────┼─────┼─────┼─────┼─────╫──────┼──────┼──────┼──────┼──────┼────────┤
│ ___ │ F10 │ F9  │ F8  │ F7  │ ___ ║ PScr │ Home │  ↑   │ End  │ ___  │BT_CLRA │
├─────┼─────┼─────┼─────┼─────┼─────╫──────┼──────┼──────┼──────┼──────┼────────┤
│ === │ F11 │Alt·F3│Ctl·F2│Sft·F1│ ___ ║ C-← │  ←   │  ↓   │  →   │ C-→  │ ===    │
├─────┼─────┼─────┼─────┼─────┼─────╫──────┼──────┼──────┼──────┼──────┼────────┤
│ === │ F12 │ F6  │ F5  │ F4  │ ___ ║ C-⇞  │ PgUp │ Ins  │ PgDn │ C-⇟  │ ===    │
├─────┼─────┼─────┼─────┼─────┼─────╫──────┼──────┼──────┼──────┼──────┼────────┤
│ === │ === │ === │ === │ === │ === ║ ===  │ ===  │ ===  │ ===  │ ===  │ ===    │
└─────┴─────┴─────┴─────┴─────┴─────╨──────┴──────┴──────┴──────┴──────┴────────┘
```

> `BT0–BT4` — переключение Bluetooth-профиля · `BT_CLR` — сброс текущего профиля · `BT_CLRA` — сброс всех профилей  
> `C-←` / `C-→` — Ctrl+Left/Right (по словам) · `C-⇞` / `C-⇟` — Ctrl+PgUp/PgDn (по вкладкам)  
> Левый энкодер: переключение приложений (Alt+Tab) · Правый энкодер: переключение вкладок (Ctrl+Tab)

## Трекбол

Поведение трекбола зависит от активного слоя:

| Слой | Режим | Описание |
|------|-------|----------|
| 0, 2 (En / Ru) | **Pointer** | Обычное управление курсором (эквивалент ~1200 CPI) |
| 3 (Sym-ru) | **Scroll** | XY → прокрутка, чувствительность ÷8 |
| 4 (F_layers) | **Sniper** | Замедленный курсор для точного позиционирования, скорость ÷3 |

## Энкодеры

| Слой | Левый энкодер | Правый энкодер |
|------|---------------|----------------|
| En / Ru | Прокрутка ↑↓ | Прокрутка ←→ |
| F_layers | Alt+Tab (переключение приложений) | Ctrl+Tab (переключение вкладок) |
| Numbers | Громкость +/− | PgUp / PgDn |

## Прошивка

### Сборка через Docker (рекомендуется)

Не требует локально установленного west/Zephyr-toolchain — достаточно Docker.

```bash
make docker-setup          # первый раз: инициализация west workspace
make docker-all            # собрать обе половины
make docker-left           # → zmk_cck_ball_left.uf2
make docker-right          # → zmk_cck_ball_right.uf2 (включает ZMK Studio)
make docker-settings-reset # → settings_reset.uf2
make docker-clean          # очистить build/
```

### Сборка без Docker (локальный west workspace)

```bash
make setup          # первый раз: west init + west update
make left           # → zmk_cck_ball_left.uf2
make right          # → zmk_cck_ball_right.uf2
make settings-reset # → settings_reset.uf2
```

### Схемы раскладки (SVG)

```bash
make keymap-svg        # генерация через локальный python3
make docker-keymap-svg # генерация через Docker (python:3-slim)
```

Результат — файлы в `keymap_svg/`: по одному SVG на слой и общий `keymap_all.svg`.

### Прошивка клавиатуры

1. Всегда прошивать **сначала левую** половину, затем правую.
2. Войти в режим загрузчика: дважды нажать кнопку reset → появится USB-накопитель.
3. Перетащить `.uf2`-файл на этот накопитель.
4. **Полный сброс**: сначала прошить `settings_reset.uf2` на каждую половину, затем заново прошить `left` и `right`.
